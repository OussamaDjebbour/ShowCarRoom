# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A bilingual (French / Arabic) **car showroom landing page** — a pitch prototype
for a dealership in Oran, Algeria. Prices are in Algerian Dinars (DZD). The whole
app is a single home page (`/`) with a state-toggled vehicle-detail overlay; there
is no backend and inventory is static mock data. It is designed to be **rebranded
for a new dealership in minutes** by editing `src/lib/siteConfig.ts` (contact info,
nav, bilingual copy) and `src/lib/mockData.ts` (inventory).

## Commands

Package manager is **bun** (`bun.lock` is canonical; `bunfig.toml` sets a 24h supply-chain
guard). A committed `pnpm-lock.yaml` is redundant with bun and can be removed.

```bash
bun install            # install deps (bunfig enforces a 24h supply-chain guard)
bun run dev            # vite dev server (http://localhost:8080)
bun run build          # production build → static dist/ (client-only SPA)
bun run build:dev      # build in development mode
bun run preview        # serve the built dist/ locally
bun run lint           # eslint .
bun run format         # prettier --write .
bunx tsc --noEmit      # typecheck (no dedicated script; tsconfig already has noEmit)
```

There is **no test runner configured** — do not invent a `bun test`/`vitest` command.
Deploy is any static host — serve `dist/` with an SPA fallback (rewrite unknown paths to
`/index.html`) so client-side routes resolve on direct load.

## Framework & build (read before touching config)

- **Plain client-side Vite + React SPA** on **React 19**, **Vite 8**, **Tailwind CSS v4**. No SSR,
  no server — this was migrated off Lovable/TanStack Start (see git history).
- Entry: `index.html` (static `<head>`: title, meta, Google Fonts) → `src/main.tsx`
  (`ReactDOM.createRoot` + `<RouterProvider>`). `src/styles.css` is imported in `main.tsx`.
- `vite.config.ts` wires plugins **explicitly**: `vite-tsconfig-paths`, `@tanstack/router-plugin`
  (`tanstackRouter`, must run before React), `@vitejs/plugin-react`, `@tailwindcss/vite`.
  - `resolve.dedupe: ["react", "react-dom", …]` is **load-bearing** — without it framer-motion
    resolves a second React copy and the app dies with "Invalid hook call". Keep it.
  - `jiti` is pinned to `^2.7.0` in devDeps because `@tanstack/router-generator` needs v2's
    `createJiti`; a stray v1 breaks `vite.config.ts` loading. Don't drop it.

## Architecture

- **Routing** — client-side **TanStack Router**, file-based under `src/routes/` (see
  `src/routes/README.md`; these are TanStack, _not_ Next.js/Remix). `routeTree.gen.ts` is
  auto-generated by `@tanstack/router-plugin` on dev/build — never edit by hand.
  `__root.tsx` is the root route: it mounts `QueryClientProvider` → `MotionConfig` →
  `LanguageProvider` → `RootLayout` (Navbar/Footer) → `<Outlet/>`, plus the 404 and error
  boundaries. Preserve `<Outlet/>`. (It is _not_ an SSR document shell — the `<head>`/`<body>`
  live in `index.html`.)
- `src/router.tsx` — `getRouter()` builds the client router with a `QueryClient` in context;
  `src/main.tsx` calls it once and renders `<RouterProvider>`.
- **`src/lib/` is the domain layer:**
  - `siteConfig.ts` — single source of truth for dealership strings, nav, and **all bilingual copy**
    (`translations.fr` / `translations.ar`). Components import copy from here, not inline literals.
  - `i18n.tsx` — `LanguageProvider` + `useLanguage()`. Locale (`fr`/`ar`) persists to `localStorage`
    (`showroom.locale`) and drives `dir`/`lang` on `<html>`. Initial render uses the default (`fr`);
    the stored locale is applied in an effect after mount.
  - `vehicles.ts` — the `Vehicle` type and `formatPriceDzd` / `formatMileage` locale-aware formatters.
  - `mockData.ts` — seed inventory (keep 3–8 entries; the grid is tuned for that).
- **Components** — `src/components/showroom/*` are the feature components (VehicleCard, HeroSection,
  ContactCTA, WhatsAppButton, …); `src/components/ui/*` are shadcn/ui primitives (new-york style, do
  not hand-rewrite — regenerate via the CLI). `src/layout/*` is the page chrome.

## Conventions

- **Styling: never hardcode hex/rgb in components.** All colors are semantic oklch tokens defined in
  `src/styles.css` (Tailwind v4 `@theme`), including brand tokens `--gold` and `--whatsapp`. Use
  semantic classes (`bg-background`, `text-gold`, …).
- **RTL is first-class.** Use Tailwind _logical_ utilities (`ms-*`, `me-*`, `ps-*`, `pe-*`, `start-*`,
  `end-*`) rather than left/right so Arabic layout and the Arabic font swap work automatically.
- **`@/` maps to `src/`.** Prefer it over deep relative imports.
- Prettier: 100-col, semicolons, **double quotes**, trailing commas everywhere. Run `bun run format`.
